02 / NÃO PRECISA CHEGAR TUDO DE UMA VEZ

Uma resposta também pode chegar aos poucos. Experimente eventos de texto e a busca por trechos de um vídeo.

EVENTOS · SSE

Uma conexão, dez mensagens.

O servidor envia um evento a cada 250 ms. A conexão fica aberta enquanto as mensagens chegam, sem uma nova requisição para cada evento.

Pronto para conectar a /stream.

As mensagens vão aparecer aqui, uma a uma.

SSE é texto enviado do servidor para o cliente. Ao receber os dez eventos, esta página fecha a conexão.

VÍDEO · RANGE

Seu vídeo, servido em trechos.

Este exemplo é opcional: o vídeo não acompanha o repositório. Você pode usar um MP4 seu ou baixar um que tenha autorização para usar.

  1. Copie o vídeo para rust_serv/public/Download.mp4.
  2. Se mudou a pasta em --root, coloque Download.mp4 nessa pasta.
  3. Clique no botão abaixo e dê play. Não é necessário reiniciar o servidor.

Ainda não verificado. Os outros testes funcionam sem vídeo.

Abrir vídeo diretamente ↗
Como enxergar os pedidos de trechos?
  1. Abra DevTools (F12) → Network / Rede.
  2. Marque Disable cache e dê play no vídeo.
  3. Avance e procure Download.mp4. Quando houver resposta parcial, veja 206 e Content-Range.

O comportamento varia conforme o navegador e o que já foi baixado. Sem vídeo, o experimento 05 acima testa Range usando o HTML desta página.

O arquivo fica apenas na sua máquina: vídeos MP4 dessa pasta são ignorados pelo Git. Se o navegador não reproduzir, experimente um MP4 com vídeo H.264 e áudio AAC.

03 / POR TRÁS DA RESPOSTA

Quatro etapas. Nada de mágica.

01 / CONEXÃO

Receber

TCP entrega bytes. Uma leitura pode conter só parte da requisição — o servidor acumula o que falta.

02 / PARSER

Interpretar

O parser valida método, caminho, headers e corpo. Mensagens inválidas e grandes demais são rejeitadas.

03 / ROUTER

Escolher

O método e o caminho selecionam um handler. Sem uma rota explícita, o servidor procura um arquivo estático.

04 / RESPOSTA

Entregar

Status informa o resultado, headers descrevem a resposta e o corpo carrega o conteúdo.
