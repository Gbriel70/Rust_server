Observe a busca por trechos

  1. Abra DevTools → Network (Rede), marque Disable cache e escolha uma rede lenta.
  2. Recarregue, dê play e avance para uma parte ainda não baixada.
  3. Procure as respostas 206 de Download.mp4 e confira Range e Content-Range.

O navegador pode buscar só os bytes necessários ao trecho escolhido, sem baixar primeiro tudo que vem antes.
